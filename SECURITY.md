# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 1.x     | ✅        |

## Reporting a vulnerability

This project is a front-end experience with **no backend, no accounts and no API keys**.
The only configurable values live in `.env` (see `.env.example`) and are public-facing URLs.

If you still discover a vulnerability — for example in the dependency chain or in how the
site handles external content — please **do not open a public issue**. Instead report it
privately via GitHub's [Security Advisories](https://github.com/abhay0069/2nd3d-website/security/advisories/new)
for this repository. You will receive an acknowledgement within 72 hours.

Thank you for helping keep OBSCURA safe.
